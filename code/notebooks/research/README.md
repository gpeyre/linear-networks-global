# Research Notebooks

These notebooks preserve the exploratory calculations used during the paper's
development. The short, maintained examples are in [../examples/](../examples/);
the six article figures are reproduced by the installed
[`linear-networks-figures` command](../../README.md).

Open this directory from the repository with Jupyter. The notebooks locate
`code/figures/` and keep their research results in `results/`. Some stored
outputs contain paths and values from earlier runs; rerun a notebook before
using its displayed results as current numerical evidence.
